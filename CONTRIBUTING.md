# Contributing

Read [the PRD](docs/PRD.md) and [repository scope](docs/REPOSITORY-SCOPE.md).
Changes should help measure whether local trajectory monitoring improves real
agent completion. Keep detection separate from policy and tool execution.

Use a stable Rust toolchain supporting edition 2024. The core uses `std`.
C headers are generated by the build dependency; no separate cbindgen install
or Makefile is required. Python packaging uses maturin.

```sh
cargo fmt --all --check
cargo test -p microloop
cargo clippy -p microloop --all-targets -- -D warnings
cargo build -p microloop-python
```

Add behavioral tests for detector boundaries, healthy controls, missing evidence,
and run isolation. Synthetic tests validate software, not recovery lift. Keep
unknown metrics unknown, record provenance, and do not tune on held-out tasks.
Include observed validation and limitations in each change description.
