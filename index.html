The Problem

Step Counters Are Blind

❌ The Blind Counter

Traditional frameworks use max_iterations = 10. But counters can’t distinguish progress from waste. A 2-step loop runs 8 more times. A valid 15-step plan gets killed. You either accept waste or break workflows.

✅ The Microloop Shield

Measures redundancy, not quantity. Blocks the first redundant repeat. Will let your agent run 100 steps if each one makes unique progress. Adaptive thresholds tighten when errors occur. Volatile fields like request IDs are automatically masked.

Capabilities

Everything You Need to Ship Safe Agents

⚡

Sub-Microsecond Fast Path

Pure Rust core hashes tool calls and checks for repetitive trajectories in 197 nanoseconds. Zero measurable overhead.

📦

Context Compression

Routes tool outputs through specialized compressors (JSON, diffs, logs, code). Reduces token count by 60-95% with lossless retrieval via CCR.

🎯

Volatile Field Masking

Automatically detects high-entropy fields like request IDs and timestamps. Masks them out so loops aren’t hidden by noisy arguments.

⚙

Adaptive Thresholding

When a tool returns an error, thresholds tighten automatically. Forces the agent to pivot immediately instead of hammering a broken endpoint.
